Project Overview

IOT HARDWARE + WEBSITE + USER APP IN ONE SYSTEM

This platform is built for real-world parking operations where hardware and software must work together in real time. Every slot has status tracking, and every status is reflected instantly on the website.

Users can check available slots, reserve instantly, and navigate to the booked space. Admins get centralized control of occupancy, alerts, and booking activity.

System Architecture

HOW INTELLIPARK INTEGRATION WORKS

1. Slot Sensor Layer

Ultrasonic/IR sensors detect vehicle presence and push occupancy status to controller nodes.

2. IoT Gateway Layer

Edge gateway validates readings, timestamps events, and sends secure updates to cloud APIs.

3. Web Platform Layer

Website dashboard renders live slot map, handles booking, and updates admin analytics instantly.

USER BOOKING PROCESS

01

Check Availability

User opens website and sees current free/occupied slots in real time.

02

Select and Reserve

User chooses slot, confirms booking, and receives reservation details.

03

Entry Validation

At gate, reservation is validated and slot is locked to avoid double booking.

04

Exit and Auto Update

On exit, slot state resets and becomes available instantly on web dashboard.
